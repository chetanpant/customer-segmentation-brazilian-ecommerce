# Customer Segmentation for Brazilian Online Retail

## Overview

This project uses machine learning to segment customers of a Brazilian online retail marketplace into meaningful groups.

The goal is to help marketing and business teams move away from generic campaigns and create more targeted strategies based on customer behaviour, spending patterns, payment behaviour, delivery experience, and review history.

This project was completed as part of the Advanced Apex Project in the BITS Pilani MSc Artificial Intelligence and Data Science programme.

---

## Problem Statement

Online retailers serve customers with very different purchasing habits, spending levels, satisfaction scores, and engagement patterns.

Using the same marketing strategy for every customer can lead to poor targeting, wasted marketing budget, and lower customer retention.

This project aims to identify distinct customer segments using the Brazilian E-Commerce Public Dataset so that business teams can design more personalized marketing and retention strategies.

---

## Business Goal

The goal of this project is to build a customer segmentation model that can:

- Identify actionable customer groups
- Understand purchasing behaviour
- Support targeted marketing campaigns
- Improve customer engagement
- Improve repeat purchase and retention strategies

The project focuses not only on model building, but also on making the output useful for business decision making.

---

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist, available on Kaggle.

The dataset includes approximately 100,000 orders and covers customer profiles, payment details, product information, seller data, and customer reviews.
